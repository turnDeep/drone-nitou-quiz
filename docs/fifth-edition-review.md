以下は第五版の改訂履歴と本文に基づく一般的な照合の観点です。提供50問すべてが以下の各改訂を出題しているわけではありません。ページは印刷ページと、表紙を1とするPDF通算ページを区別しています。

例外が記載された場合でも、他の航空法上の規制や他法令まで一括で免除されるとは解釈しません。教則の記載と他の公式資料に食い違いが見つかった場合は、解釈を断定せず `needs_revision` にして出題から外します。

## 問題単位の照合手順

1. 写真のファイル名、ページ、問題番号を付け、問題文・三つの選択肢・元の正答・元の解説を転記します。
2. 「正しい／誤っている」「以上／超える／未満」「必要／不要」、数値、否定表現、図の注記を写真と目視照合します。判読不能な箇所は推測で埋めません。
3. 第五版の該当節を確認し、正答だけでなく、誤答選択肢の説明が成立するかも照合します。複数正解や正解なしになる問題は修正対象にします。
4. 写真の元の表現を照合記録に残し、アプリ用の問題・選択肢・正答・解説の修正版を別途記録します。
5. 二等の範囲と整合することを確認し、根拠URL、節、印刷ページ、PDF通算ページ、確認日、修正理由を記録します。
6. 内容を確認できた問題だけ `review.status` を `verified` にします。`pending` と `needs_revision` は出題対象外です。
